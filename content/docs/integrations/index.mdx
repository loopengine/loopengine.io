Connect Loop Engine through three public categories — **[Providers](/docs/concepts/runtime-taxonomy#providers)**, **[Channels](/docs/concepts/runtime-taxonomy#channels)**, and **[Integrations](/docs/concepts/runtime-taxonomy#integrations)**. Every adapter preserves the same governance model: **guards enforced**, **actors attributed**, **evidence** on each transition.

→ [Runtime Taxonomy](/docs/concepts/runtime-taxonomy) · [Architecture](/docs/getting-started/architecture)

**Hosted governance:** [Loop Engine Cloud (HTTP API)](/docs/integrations/loop-engine-cloud-api) at `loops.betterdata.co` — multi-tenant connectors and API keys. **OSS runtime:** self-host with `@loop-engine/sdk` in your infrastructure.

**Developer note:** npm packages implement [IntegrationAdapter archetypes](/docs/concepts/integration-adapter) (`Store`, `Registry`, `AI`, `EventBus`). Public grouping below follows the product taxonomy, not package folder names.

## ⟩ Providers

Intelligence sources and AI systems participating as governed actors (or tool steps for retrieval).

Use any major LLM as a governed actor. Provider actor adapters produce the same `AIAgentActor` shape — switching providers requires changing one import. Perplexity Sonar covers **grounded retrieval with citations** as a `ToolAdapter` for research steps.
