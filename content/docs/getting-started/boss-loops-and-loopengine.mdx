Boss Loops is the product and hosted platform for governed decision loops. It is not a generic workflow engine. LoopEngine is the open-source execution library Boss Loops uses to run those loops. The product was originally introduced as LoopEngine. The library kept that name and the `@loop-engine/*` packages.

## Comparison

| | Boss Loops | LoopEngine |
| --- | --- | --- |
| Identity | Commercial product and hosted platform at [app.bossloops.io](https://app.bossloops.io) | Open-source execution library |
| Primary purpose | Governed decision loops | Execution of defined loops |
| Interface | Hosted application and [Cloud API](/docs/cloud/api-reference) | TypeScript library and packages |
| Authentication | Organization API keys and hosted authorization | Application-controlled integration |
| Execution | Uses LoopEngine | Provides execution primitives, including `createLoopSystem` |
| Human approvals | Hosted approver assignments | Library-level actors and guards |
| Installation | Hosted service | `@loop-engine/*` packages |

The hosted application does not expose the library's in-process API as the customer HTTP contract.

## What does not carry over

Library behavior and hosted behavior are different surfaces.

- **Actors.** In LoopEngine, a transition names an actor type on the definition (`human`, `automation`, `ai-agent`, or `system`). On the Cloud API, the actor of record is the authenticated caller. Send `X-Actor-Type: user`, `system`, or `llm`. The transition body uses `human`, `ai`, or `system`, and `ai` is stored as `ai-agent`. A body cannot name a different person.
- **Approval.** LoopEngine can mark a transition as requiring approval. Boss Loops Cloud accepts a human approval only when that person has an approver assignment. An API key cannot approve by putting someone's name in the body.
- **Organizations.** Cloud calls are limited to the organization that owns the API key. A loop from another organization is not returned. The library has no organization API key.
- **Lifecycle.** `POST /api/v1/loops` creates a hosted instance. It does not call the library `start` operation. See the [Cloud API](/docs/cloud/api-reference).
- **Packages.** Do not rename imports to `@boss-loops/*`. Those packages are not the published interface.

`X-Actor-Type: system` authenticates on the Cloud API and then cannot complete a transition. Do not document that as a supported hosted operation.
