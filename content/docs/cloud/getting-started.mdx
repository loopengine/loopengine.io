Two ways to run a loop. They are not the same product surface. See [Boss Loops and LoopEngine](/docs/getting-started/boss-loops-and-loopengine).

| | **LoopEngine library** | **Boss Loops Cloud** |
| - | --- | --- |
| What it is | Open-source execution in your process | Hosted Boss Loops product |
| What you get | Definitions, guards, actors, and events | Organization loops, API keys, approver assignments, and managed Slack and Google connectors |
| Credentials | None for the quick start | An organization API key, issued for your organization |
| Where | [Library quick start](/docs/getting-started/quick-start) | [Cloud API](/docs/cloud/api-reference) |

## Local

```bash
npm install @loop-engine/sdk
```

Follow the [quick start](/docs/getting-started/quick-start). That example runs in your process. It does not call Boss Loops Cloud, and it does not need an API key.

`@loop-engine/sdk` on npm is `1.0.0-rc.1`. See [Installation](/docs/getting-started/installation) for the rest of the package cohort.

## Hosted

Boss Loops Cloud is at **[app.bossloops.io](https://app.bossloops.io)**. Organizations are provisioned with Better Data. Start from the [Cloud overview](/docs/cloud) to request access.

When you have an organization API key:

```bash
curl -sS \
  -H "Authorization: Bearer $BOSS_LOOPS_API_KEY" \
  -H "X-Actor-Type: user" \
  "https://app.bossloops.io/api/v1/loops/catalog"
```

`BOSS_LOOPS_API_KEY` is `le_` plus 32 hex characters. Send `X-Actor-Type` on every call. Read [Authentication](/docs/cloud/api-reference#authentication) before transitioning a loop: the body actor cannot name a different person, and a system-classified key cannot complete a transition today.

Live Slack approval and Google Sheets apply are configured in the hosted product. They are not part of the OSS quick start.
