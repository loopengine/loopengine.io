**Boss Loops Cloud** is the hosted Boss Loops product at
[app.bossloops.io](https://app.bossloops.io). It uses [LoopEngine](/docs/getting-started/boss-loops-and-loopengine),
the open-source execution library, and adds organization API keys, approver assignments,
and managed connectors. The library quick start is a different surface. Commercial terms:
[Pricing](/pricing).

## See the product: the governed Decision Record

The canonical product demo is the **Alpine demo Decision Record** — a supplier invoice
decision (`INV-2026-004521`) carrying frozen evidence, the policy that applied, the approval
captured with the evidence presented, and preview semantic evidence from
[Looker](/docs/concepts/evidence-providers#looker-semantic-evidence-preview). It shows what Boss Loops sells: a
decision you can defend a year later.

## What is Boss Loops Cloud?

Boss Loops Cloud, hosted at **[app.bossloops.io](https://app.bossloops.io)**, is the managed
product. You integrate with the [Cloud API](/docs/cloud/api-reference). Better Data operates
the service, isolation between customer organizations, and upgrades. Execution goes through
LoopEngine (`@loop-engine/*`). See [Boss Loops and LoopEngine](/docs/getting-started/boss-loops-and-loopengine).

**Library alternative:** install `@loop-engine/sdk` and follow the
[quick start](/docs/getting-started/quick-start). That does not provision a Cloud organization.

## What you get

See [Cloud operations](/docs/cloud/operations) for organization isolation, API keys,
approver assignments, and history.

## API

The hosted product exposes a versioned HTTP API. The
[Cloud API reference](/docs/cloud/api-reference) is the customer contract. It is not a
generated OpenAPI page.

## LoopEngine library vs Boss Loops Cloud

| | LoopEngine (`@loop-engine/sdk`) | Boss Loops Cloud ([app.bossloops.io](https://app.bossloops.io)) |
| - | ------------------------- | ----------------------------------------------------------- |
| Cost | Free (Apache-2.0) | See [Pricing](/pricing) |
| Setup | You operate | Better Data operates the service |
| Who can approve | Your `actors` list and application checks | Approver assignment on the decision loop |
| Integrations | Your adapters | Organization API key, plus Slack and Google in the product |
| History | Your event bus and store | `GET /api/v1/loops/{aggregateId}/history` |
| SLA | Self-managed | Better Data SLA |
