## When to require human approval

Use human gates for:

- high-value financial commitments
- irreversible actions
- regulated or compliance-heavy decisions

Self-hosted gates use the transition `actors` list and `canActorExecuteTransition` from `@loop-engine/actors`. Boss Loops Cloud adds a separate check for human approve-signals: the signed-in person must have an approver assignment on that decision loop. An API key cannot pass that check by naming a person. See [Cloud API](/docs/cloud/api-reference#human-approval).

## Pattern A: omit `ai-agent` from `actors`

```yaml
- id: settle_invoice
  from: MATCHED
  to: SETTLED
  actors: [human, automation]
```

If an `ai-agent` attempts this transition, `canActorExecuteTransition` returns `authorized: false` and `requiresApproval: false`, with reason `Actor type not allowed for this transition`.

## Pattern B: AI constraints in authorization

`AIActorConstraints` in `@loop-engine/actors`:

```ts
interface AIActorConstraints {
  requiresHumanApprovalFor?: TransitionId[]
}
```

When an `ai-agent` attempts a transition whose id appears in `requiresHumanApprovalFor`, `canActorExecuteTransition()` returns `authorized: true` and `requiresApproval: true`. The caller still has to stop and wait for a human. The helper does not reject the actor by itself.

## Pending approval sequence

```ts
const aiAuth = canActorExecuteTransition(aiActor, transition, constraints)
if (aiAuth.requiresApproval) {
  // authorized is still true; your app creates the human review task
}

// Later, human executes same transition:
await engine.transition({
  aggregateId,
  transitionId,
  actor: { type: 'human', id: 'approver@acme.com' },
  evidence: { approved: true, approval_ticket: 'APR-123' }
})
```

<Callout variant="important" title="Per-transition gating only">
`AIActorConstraints` ships with a single field, `requiresHumanApprovalFor`. Boss Loops does not provide a built-in consecutive-AI-transition circuit breaker. Track that policy in your application and translate it into per-transition entries on this list, or omit `ai-agent` from `actors`.
</Callout>
