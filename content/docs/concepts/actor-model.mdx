## Why actors matter

Every transition is attributed to an actor in the transition record and emitted events.  
Nothing executes anonymously.

This page is the **self-hosted** engine (`@loop-engine/actors`). In Boss Loops Cloud the actor of record is the authenticated caller — an organization API key or a signed-in person — and the transition body cannot substitute a different person or actor class. See [Cloud API — actor identity](/docs/cloud/api-reference#actor-identity-on-a-transition).

## Actor types

### `human`

Use when a person executes a transition.

```ts
const actor = {
  type: 'human' as const,
  id: actorId('drew@acme.com'),
  userId: 'user_drew',
  displayName: 'Drew',
}
```

### `automation`

Use for jobs, integrations, and rule engines.

```ts
const actor = {
  type: 'automation' as const,
  id: actorId('system:po-router'),
  serviceId: 'po-service',
}
```

### `ai-agent`

Use for model-driven recommendations or execution.

```ts
const actor = {
  type: 'ai-agent' as const,
  id: actorId('agent:forecaster'),
  modelId: 'claude-3-5-sonnet',
  provider: 'anthropic',
}
```

### `system`

Use for internal runtime/platform initiated actions.

```ts
const actor = {
  type: 'system' as const,
  id: actorId('system:loop-engine'),
  componentId: 'loop-engine',
}
```

## AI evidence

`@loop-engine/actors` exports `buildAIActorEvidence` for model submissions. It requires `modelId`, `provider`, `reasoning`, and `confidence` (0 through 1), and returns evidence plus `promptHash` when you pass `prompt`. There is no `buildActorEvidence` helper.

## Authorization checks

`canActorExecuteTransition(actor, transition, constraints?)` returns:

```ts
{ authorized: boolean; requiresApproval: boolean; reason?: string }
```

```ts
import { canActorExecuteTransition } from '@loop-engine/actors'

const auth = canActorExecuteTransition(actor, transition)
if (!auth.authorized) {
  console.log(auth.reason)
}
```

<Callout variant="important" title="AI actor rule">
Do not make `ai-agent` the only allowed actor on a critical transition.
Include `human` or `automation` as a fallback execution path.
</Callout>
